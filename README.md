# 🎮 Higher Lower Game

A command-line Python game where you compare two randomly selected accounts and guess which one has more followers.

The goal is simple: **make the correct comparison and build the highest score possible.**

## 📌 How It Works

1. The game displays two accounts: **A** and **B**.
2. Each account has a name, description, country, and follower count.
3. You choose which account has more followers.
4. If your answer is correct, your score increases.
5. The game continues until you make an incorrect guess.
6. Your final score is displayed when the game ends.
